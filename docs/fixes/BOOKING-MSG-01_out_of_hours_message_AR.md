# BOOKING-MSG-01 — رسالة خاطئة عند الحجز خارج دوام الحلاق (لوحة الموظفين)

> **التاريخ:** 2026-09-25 — **الحالة:** ✅ مُصلَحة

## البلاغ
الحلاق يحجز من الـ Timeline لشخص خارج ساعات دوامه، فتظهر رسالة `Please fill in all service details` (إنجليزية دائماً). الرسالة لا تشرح الخطأ.

## السبب الجذري
1. السحب على عمود الحلاق يفتح المودال مع `_preselectedProvider`.
2. `loadProvidersForService()` تسأل `getProviderAvailabilityForServiceAtTime()`، فيأتي الحلاق `available: false` و`reason: outside_hours`. المودال **لا يختاره** ويعرضه رمادياً فقط، دون أي تنبيه.
3. `provider_id` يبقى فارغاً. `saveBookingFromAlpine()` تحذف الصف بـ `array_filter`، فلا يبقى شيء، فتظهر الرسالة العامة المكتوبة يدوياً بالإنجليزية.

**خلل ثانٍ اكتُشف في نفس المكان:** `array_filter` كانت تحذف الصفوف الناقصة **بصمت**. في حجز بخدمتين، إذا كان حلاق الخدمة الثانية رمادياً، **يُحفظ الحجز بالخدمة الأولى فقط** دون أي إشعار.

## الحل: منع الحجز خارج الدوام + إعلام واضح بكل اللغات
الحجز خارج الدوام **ممنوع أصلاً**:
- المودال لا يسمح باختيار الحلاق الرمادي.
- السيرفر يرفض عبر `BookingValidationService::validateProviderScheduleWindow()`.
- الاستثناء الوحيد هو «الحجز الإجباري» `force_booking` لمن يملك الصلاحية.

الإصلاح يجعل هذا المنع **مفهوماً**:

| الطبقة | التعديل |
|---|---|
| المودال (`staff-dashboard.blade.php`) | إذا كان الحلاق الذي بدأ منه الحجز غير متاح، يبقى محفوظاً (`bs._blocked`) ويظهر **صندوق أحمر**: «Aisha Al Zaabi غير متاح الساعة 18:00 (خارج ساعات الدوام). اختر وقتاً آخر أو مقدم خدمة آخر.» تغيير الوقت إلى ساعة يعمل فيها يعيد اختياره تلقائياً. |
| زر الحفظ (`submitBooking`) | يتحقق قبل الإرسال ويعرض السبب الدقيق بدل استدعاء السيرفر |
| السيرفر (`StaffDashboard::bookingRows()` + `missingProviderMessage()`) | يستبدل `array_filter` والرسالة الثابتة. الصف بلا خدمة يُتجاهل كما كان، والصف بخدمة ناقصة الوقت أو الحلاق **يرفض الحجز كله** برسالة دقيقة (أو يسمّي الحلاق وسبب عدم توفره إذا أرسل المودال `preselected_provider_id`) |
| `BookingValidationService` | رسائل كانت إنجليزية ثابتة صارت مترجمة: خارج الدوام (مع الساعات)، إجازة، وقت مضى، مهلة الحجز المسبق، تداخل الخدمات. **تنطبق على الـ API أيضاً** بلغة الطلب |
| `Selected customer not found` | مترجمة |

### الرسائل الجديدة
- `lang/{ar,de,en}/dashboard.php` → `booking_modal.errors.*`: `service_required`، `time_required`، `provider_required`، `provider_unavailable`، `no_provider_at_time`، `customer_not_found`.
- `lang/{ar,de,en}/booking.php`: `outside_working_hours`، `provider_time_off`، `slot_in_past`، `min_advance`، `services_overlap`.

المودال يأخذ نفس نصوص `booking_modal.errors` عبر `@js(__('dashboard.booking_modal.errors'))`، فالرسالة في المتصفح والرسالة من السيرفر **نص واحد**.

## الاختبارات — `tests/Feature/Booking/DashboardBookingMessagesTest.php` (8)
- الحلاق خارج الدوام → الاسم والسبب بالإنجليزية والألمانية والعربية.
- لا حلاق متاح في تلك الساعة → «لا يوجد مقدم خدمة متاح…».
- يوجد حلاق متاح لكن لم يُختر → «يرجى اختيار…».
- خدمتان والثانية بلا حلاق → رفض، ولا يُنشأ أي موعد (كان يُحفظ نصف الحجز).
- صف إضافي بلا خدمة → يُتجاهل والحجز ينجح.
- طلب مُزوَّر يسمّي حلاقاً خارج الدوام → رسالة السيرفر مترجمة مع الساعات.

إضافة لذلك: عُرضت الواجهة فعلياً في اختبار، وفُحص JavaScript الناتج بـ `node --check` (سليم). ونجحت 329 من اختبارات الحجز والدفع والتذكيرات واللوحة.
